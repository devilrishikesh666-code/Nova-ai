
# NOVA AGENT

A futuristic AI assistant developed by Rishikesh Singh.

## Features

- AI chat powered by OpenRouter
- Coding assistant
- Futuristic animated robot
- Image Studio interface
- Mobile responsive interface
- Secure backend API integration
- Customizable AI model

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express
- OpenRouter API

## Installation

Install Node.js 18 or later.

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Open the project folder:

cd nova-agent

Install dependencies:

npm install

Create a .env file and configure your API key.

Start NOVA:

npm start

Open:

http://localhost:3000
